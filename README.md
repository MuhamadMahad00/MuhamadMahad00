## 🚀 Featured Projects

### 1. Pakistan Legal AI Assistant: Advanced RAG Chatbot
A legal-document question-answering assistant that grounds its responses in supplied Pakistani legal documents and provides citations.

**Tech:** Python, FastAPI, RAG, FAISS, BM25, Reranking, Groq
**Repository:** [Pakistan-Legal-AI-Assistant-Advanced-RAG-Chatbot](https://github.com/MuhamadMahad00/Pakistan-Legal-AI-Assistant-Advanced-RAG-Chatbot)

### 2. Smart MCP Autonomous AI Assistant
An AI assistant built with LangGraph and MCP that connects an LLM to tools for file operations, browsing, scraping, and API interactions.

**Tech:** Python, LangGraph, MCP, Gemini, FastAPI, SSE, Streamlit
**Repository:** [Smart-MCP-Autonomous-AI-Assistant](https://github.com/MuhamadMahad00/Smart-MCP-Autonomous-AI-Assistant)

### 3. Freelancer Tax AI
A full-stack AI application for Pakistan-focused freelancer tax calculations, with RAG-based question answering.

**Tech:** React, FastAPI, Gemini, ChromaDB, MongoDB
**Repository:** [Freelancer Tax AI](https://github.com/MuhamadMahad00/Full-stack-AI-application-for-Pakistan-Freelancer-Tax-calculations-and-RAG-based-Chat)

### 4. AI Job Matching System
A semantic job-matching application that compares job descriptions with candidate profiles using embeddings and vector similarity.

**Tech:** Python, FastAPI, Streamlit, FAISS, MiniLM, Groq
**Repository:** [AI-Job-Matching-System](https://github.com/MuhamadMahad00/-AI-Job-Matching-System)

### 5. AI Personal Assistant with n8n
An AI-powered personal assistant that connects workflows and services to automate everyday tasks.

**Tech:** n8n, Python, Streamlit, Gemini, APIs
**Repository:** [AI-Personal-Assistant-n8n-Streamlit](https://github.com/MuhamadMahad00/-AI-Personal-Assistant-n8n-Streamlit)

### 6. FuturePath: AI Career Counselling
A multilingual career-counselling system that helps Pakistani students explore career paths using AI, assessments, and explainable machine learning.

**Tech:** FastAPI, React, Supabase, Groq, XGBoost, SHAP, Whisper
**Repository:** [career-counsling-system-project](https://github.com/muhammadmahad9999/career-counsling-system-project)
