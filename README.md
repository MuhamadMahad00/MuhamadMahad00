## 👋 About Me

I'm **Muhamad Mahad**, a Computer Science graduate from the University of Engineering and Technology (UET), Peshawar, Pakistan.

My work focuses on building practical AI applications, retrieval-augmented generation systems, AI agents, and workflow automations that solve real-world problems.

- 🤖 **Generative AI:** LLM-powered applications, chatbots, and RAG pipelines.
- 🧠 **Agentic AI:** Multi-agent workflows, LangGraph, tool calling, and MCP.
- ⚙️ **AI Automation:** Workflow design, integrations, and automation using n8n.
- 💻 **Backend Development:** Python, FastAPI, and REST APIs.
- 🌐 **Application Development:** JavaScript and AI-powered web applications.
- 🔍 **Continuous Learning:** Exploring better ways to build useful, reliable AI systems.

I enjoy taking an idea from concept to implementation and learning through hands-on projects.
